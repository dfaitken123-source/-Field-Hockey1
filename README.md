# Field Hockey Tournament Host (Vite + React)

A ready-to-deploy Vite project for your Field Hockey Tournament Host app.

## Local development

```bash
npm install
npm run dev
```

Visit http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

1. Create a new project at vercel.com and select this folder (or push to GitHub and import).
2. Framework preset: **Vite** (auto-detected)
3. Build command: `npm run build`
4. Output directory: `dist`

## Deploy (Netlify)

- Build command: `npm run build`
- Publish directory: `dist`
